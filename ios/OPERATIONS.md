# 南图：权利申请、未成年人及保留删除的落实流程

## 已由运营者选择的规则

- 账号与社交服务面向14周岁及以上用户；14至17周岁与监护人共同阅读并确认监护人同意。
- 收到个人信息权利申请后7个工作日内首次答复，通常15个工作日内处理并反馈。需要补充必要材料或事项复杂时，在期限届满前说明原因和预计时间。
- 公开受理人为黄君华，邮箱 `nonto@foxmail.com`。期限是运营安排，不是对所有法律期限的概括；有更短适用要求时按其处理。

## 每封申请的实际处理

1. 定期查看邮箱，登记接收日期、案件编号、类型、账号编号、必要核验状态和承办人。依实际法定工作日历计算答复与处理日期，包含节假日调休，不能仅按周一至周五机械计算。
2. 7个工作日内答复受理情况。账号请求用相称的账号归属信息核对；监护人请求核对必要的监护关系。不要索取密码、验证码、无关完整证件或全部聊天记录。
3. 查阅、复制请求仅导出申请人依法可取得的信息，遮盖他人信息。更正、删除、撤回请求记录处理范围及结果。举报与权利请求分别登记，不能把投诉自动认定为成立。
4. 通常15个工作日内完成并答复。不能满足时说明理由；需要补充材料、复杂调查或保留特定记录时，说明依据、限制用途及预计完成时间。不要用反复索要材料无限延迟。
5. 复核请求保留原编号、补充事实及复核结果。完成后去掉不再需要的身份材料，只保留必要、受限的处理记录；具体留存期限需与争议和实际运营要求一并确定。

空白模板为 `operations/rights-request-register.csv`。实际台账包含个人信息，须复制到运营者受控的非公开位置，限制访问；不要把真实案件填回公开仓库。

首次答复模板：

> 已收到你的申请，编号【案件编号】。申请类型为【类型】，涉及【范围】。目前【已受理／需要补充的最少材料】。预计于【日期】前反馈处理结果。请勿发送密码、验证码或无关完整证件。如有异议，可在本邮件线程补充说明。

完成／部分完成模板：

> 关于【案件编号】，已于【日期】完成【具体处理范围】。【未完成或保留项目、理由及预计时间（如有）】。如你对结果有异议，可在本邮件线程补充事实和复核理由。

这些模板不自动发送邮件；运营者需核实具体内容后答复。

## 未成年人事件

- 原生入口的年龄范围和监护人确认是自行声明，不能当作实名认证或真实年龄证明；尚需核对其他客户端与后端的入口。
- 不满14周岁者不能继续进入原生账号服务，但仍可离线阅读规则、联系南图。不要为了拒绝使用而收集其完整出生日期或身份证件。
- 收到疑似低龄或冒用年龄报告时，先核对必要信息、限制不必要的处理和风险内容，再处理相应账号及监护人请求。实际禁用、删除和恢复操作必须留有受限的处理记录。
- 14至17周岁用户的举报、屏蔽、可见范围、隐私和监护人申请按对应流程处理。不得把商店内容年龄分级当作已经实现监护人同意机制的证据。

## 保留与删除：需要实施的方案

以下是实施范围，不是已经在生产完成的声明。尚未填入公开配置的固定期限，也没有执行生产删除。

| 数据 | 正常使用期间 | 删除／注销时的实施范围 |
| --- | --- | --- |
| 账号与资料 | 为维护账号和展示资料保存必要数据 | 账号身份、认证凭据、头像封面、隐私设置及相关资料；使旧登录和实时连接失效 |
| 动态与互动 | 为展示用户内容和提供互动保存 | 处理自有动态、评论、引用及关联数据；不能因删除一人账号误删他人的独立数据 |
| 私信与群聊 | 为通信和历史记录保存 | 处理申请人的消息、附件、引用预览、参与记录和补发日志；接收方另行保存的副本须单独说明 |
| 媒体对象 | 只在相应使用目的仍存在时保存 | 数据库链接与腾讯云COS对象分别核对；覆盖未完成上传、历史头像、对象版本和孤立文件，不能只删URL |
| 社群与漫展 | 为共享内容及管理服务保存 | 转移或终止管理关系须有明确流程，不能连带删除其他成员内容或留下无法管理的社群 |
| 验证码与访问记录 | 验证、限流及安全需要 | 验证码过期不等于数据库记录已删除；安全日志应有明确用途、期限、访问限制及到期清理 |
| 备份与快照 | 仅在实际配置和必要的恢复目的下保存 | 核对数据库备份、云盘快照、COS版本及其他副本；确定轮换期限，恢复时重新执行已确认的删除请求 |

当前后端注销接口只调用 `db.delete(current)`，不能据此确认表中范围已经实现。关联外键、共享所有权、媒体与备份清理需要先落实再验收。

后端 `NonToPython/ios` 提供只读检查：

```sh
python scripts/account_privacy_inventory.py --env-file /www/wwwroot/NonToPyDev/NanTuPy/.env --account-id TEST_ACCOUNT_ID
```

运行前将 TEST_ACCOUNT_ID 替换为专用测试账号的数字ID。脚本只读取表结构和数量，帮助检查真实数据库中的关联关系；不删除、不建表、不迁移、不输出用户名、邮箱、消息、验证码或数据库连接串。不需要将环境文件或密钥发给任何人。使用专用测试账号及尽可能只读的数据库权限。

还需从阿里云与腾讯云控制台核对：自动快照、数据库备份、COS版本控制、生命周期及保留天数。没有这些配置依据，不能写成“没有备份”或“30天后全部清空”。

## 上线验收

在专用账号验证删除前后数据库、登录、推送、实时连接、媒体访问及备份恢复处理。记录实际结果后填写公开保留删除规则，再更新运行验收标记；未完成项继续阻止正式发布。
