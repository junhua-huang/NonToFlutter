2. 機能ごとに処理される情報

アカウントとセキュリティ: 送信された電子メール、ユーザー名、パスワード、および電子メール確認コードは、登録、サインイン、パスワード回復、およびアカウントのセキュリティに使用されます。パスワードは検証のためにネットワーク経由でサーバーに送信されます。クライアントは、サインイン トークンをシステム キーチェーンに保存します。電子メール認証は法定の実名認証ではありません。登録またはサインインに必要な情報がなければ、アカウント機能を使用することはできません。

プロフィール: 選択した表示名、プロフィール、アバター、カバーはインタラクションであなたを識別し、プロフィールに表示されます。プロファイルの編集で修正してください。プライバシー設定では、プロフィールの公開設定、電子メールの表示、検索機能、友達リクエストを送信できるユーザーを管理します。非公開にしたい連絡先情報を公開プロフィールに記載しないでください。

コンテンツとソーシャル機能: 投稿、コメント、プライベートおよびコミュニティのメッセージ、選択した画像とビデオ、友情、フォロー、いいね、およびインタラクションの記録は、コンテンツの保存、送信、表示、関係の維持、未読ステータスの更新に使用されます。メッセージングは​​、会話、送信者、受信者、送信時刻と配信、既読または取り消しステータスも処理します。プライベート メッセージはサーバーによって処理され、保存されます。このバージョンでは、エンドツーエンドの暗号化保証は提供されません。

検索とフィード: 検索語と検索タイプは結果を返すためにサーバーに送信され、アカウントの検索履歴に記録される場合があります。 Explore の検索履歴をクリアします。これにより、必要なセキュリティ ログは削除されません。ネイティブのホーム画面には現在、おすすめフィードなしで「最新」と「For you」が表示されます。最新の注文投稿を公開時間ごとに表示します。 For you では、通知、コメント、いいね! に関連する投稿が最新順に収集されます。フィードを切り替えても、既存のインタラクションや閲覧記録は削除されません。説明または処理に関するリクエストについては、このポリシーに記載されている電子メールまでお問い合わせください。

確認申請書: 提出することを選択した役割、仕事のつながり、連絡先の詳細、および補足資料は、申請書の審査と資格の表示に使用されます。連絡先の詳細には、お客様が提供した電話番号が含まれる場合があります。役割または作成者の検証は、自動的に法定の実名検証を構成するものではありません。無関係な ID 番号とアドレスを編集します。無関係な身分証明書、銀行カード、医療記録、または他人の機密情報を提出しないでください。機密情報が必要な場合は、その必要性と影響について別途説明し、必要な許可を得る必要があります。単一の政策協定でこのプロセスを置き換えることはできません。

レポートとサポート: レポートの理由、関連ユーザー、投稿、コメントまたはメッセージ ID、電子メールで送信された説明、スクリーンショット、連絡先の詳細は、問題の特定、調査、対応、データ権利要求の処理に使用されます。レポートには、送信することを選択したチャットの抜粋が含まれる場合があります。関連する資料のみを提供し、パスワードや確認コードは送信しないでください。

サービス アクセス: ネットワーク プロバイダーとリソース プロバイダーは IP アドレスを受け取り、接続に必要な情報を要求します。リモートの画像、ビデオ、ページを読み込むと、リソース要求も生成されます。アクセス ログとセキュリティ ログは、サービスの接続、不正行為の制限、トラブルシューティング、苦情の処理に使用されます。保持と削除についてはセクション 7 を参照してください。

3. システムの権限とデバイスの機能

写真とビデオ: Apple のシステム フォト ピッカーを通じてアイテムを選択します。クライアントは、写真ライブラリ全体へのアクセスを要求せずに、プレビューおよびアップロードのために選択されたアイテムを読み取ります。キャンセルしてもテキスト機能には影響しません。 [画像の保存] を選択した場合にのみ、クライアントは現在の画像を保存するための写真の追加権限を要求します。拒否しても画像の閲覧やチャットには影響しません。写真はアップロード前にサイズ変更され、JPEG として再エンコードされます。選択したファイルからビデオが読み取られてアップロードされます。ビデオやその他のファイルには、作成時間、場所、その他のファイル プロパティが含まれる場合があります。共有したくない情報を確認して削除してから送信してください。

カメラ: カメラの許可は、チャット添付メニューでカメラを選択した場合にのみ要求されます。写真は Apple のシステム カメラ インターフェイスを通じて撮影されます。結果はサイズ変更され、JPEG として再エンコードされ、送信プレビューに配置されます。送信を確認した後にアップロードされます。写真には自動的に保存されません。音声は収集されず、連続録音は行われません。カメラの許可を拒否または取り消しても、写真の選択やテキスト メッセージには影響しません。 iOS 設定で認証を管理します。

通知: このポリシーに同意し、正常にサインインしてメイン アプリに入ると、システム通知を選択していない場合、クライアントは通知許可を要求します。通知はメッセージとインタラクションのアラートを提供します。通知設定でそれらを有効にしたりテストしたりすることもできます。拒否後、アプリは繰り返しシステム承認を要求しません。 [設定] リンクを使用して、iOS 設定で変更します。拒否した後もアカウントとチャット サービスを使用することはできますが、これらのシステム アラートは受信しなくなります。システム権限を付与しても、アカウントで無効になっているプッシュまたはアラートの設定は上書きされません。 iOS の設定 → 通知 → NonTo およびアプリの設定 → 通知設定で、権限、プッシュ、メッセージ アラートとサウンドを管理します。

クリップボードと共有: 選択したメッセージは、[コピー] を選択した場合にのみクリップボードに書き込まれます。既存のクリップボードの内容は積極的に読み取られません。システム共有シートで宛先を選択します。受信者は共有コンテンツまたはリンクを受け取ることができます。リンクを共有しても、元のコンテンツの権限は自動的に変更されません。外部の Web サイトやアプリは、開いた後、独自のルールに従ってアクセスを処理します。

その他の機能: ネットワーク アクセスは、サインイン、読み込み、アップロード、メッセージの同期に使用されます。写真や通知の許可には依存しません。

年齢宣言: 最初の使用時に、ネイティブ アカウント サービスへのアクセスを制御するために、選択した年齢範囲と必要な保護者の同意確認がこのデバイスに記録されます。生年月日や身分証明書はここでは収集されません。範囲についてはセクション 10 を参照してください。

現在のネイティブ バージョンでは、連絡先、位置情報、またはマイクへのアクセスは要求されず、広告追跡、サードパーティの分析、支払い、またはサードパーティのサインイン SDK は統合されません。イベントの場所を手動で入力しても、デバイスの場所は読み込まれません。新しい許可または目的には、まず最新の情報と法律で要求される認可が必要です。

4. メッセージとプッシュ通知

プッシュ通知が有効になっている場合、クライアントは NonTo サーバーに Apple プッシュ トークン、ランダムなインストール識別子、バインディング検証資格情報、デバイス タイプ、アプリのバージョン、フォアグラウンド/バックグラウンド状態を送信します。サーバーは、メッセージのルーティング、状態の更新、およびバインド解除のために、これらを現在のアカウントにバインドします。ランダムなインストール識別子は、広告識別子でもハードウェアのシリアル番号でもありません。

リモート通知は、Apple プッシュ通知サービス (APN) を通じて配信されます。現在のペイロードは、プライベート メッセージ テキストや送信者の表示名を含まない汎用アラートを使用しますが、受信者アカウントのルーティング ID、通知、メッセージおよび関連コンテンツ、重複排除 ID が含まれています。一般的なアラートでもアプリの使用が明らかになる可能性があります。システム設定でプレビューを調整します。 APN はプッシュ識別子と配信に必要な情報を処理します。 Apple の処理情報についてはセクション 5 を、地域および関連取り決めについてはセクション 7 を参照してください。

プッシュを無効にするかサインアウトすると、クライアントはデバイスのバインドを解除しようとします。ネットワークが利用できない場合、保留中のバインド解除は保存され、後で再試行されます。このデバイスのアラートをすぐに停止するには、システム通知を無効にします。通知を無効にしたりサインアウトしても、配信されたメッセージやサーバー アカウントは削除されません。

7. 保管、保持および削除

このデバイスの場合: サインイン トークンとプッシュ バインディング検証資格情報はキーチェーンに保存されます。設定、同意のバージョンと時刻、アカウント テキストの下書き、送信トレイとメッセージ同期の進行状況はローカルに保存されます。コンテンツ キャッシュはキャッシュ ディレクトリ内のアカウントごとに分離され、ファイル キャッシュは iOS ファイル保護を使用します。システムはキャッシュを再利用できるため、キャッシュが唯一のバックアップであってはなりません。投稿の下書きには、テキスト、視聴者、表示された ID、および選択した写真またはビデオが保持されます。メディア ドラフトはアカウントごとにアプリケーション サポート ディレクトリに保存され、iOS ファイル保護が使用され、システム バックアップから除外されます。公開を確認した場合にのみアップロードされます。同じコンポーザを再度開くと、それらを復元できます。関連する下書きは、公開が成功した後、明示的に破棄またはアカウントが削除された後にクリアされます。ローカル ドラフトを唯一のバックアップとして使用しないでください。

ローカル キャッシュをクリアすると、下書き、送信トレイ、キーチェーン、サーバー データではなく、コンテンツ キャッシュとネットワーク キャッシュがクリアされます。サインアウトはアカウントの削除ではないため、同じアカウントが再度サインインすると下書きが戻る可能性があります。サーバーがアカウントの削除を確認した後、クライアントはそのアカウントの下書き、キュー、同期の進行状況、およびキャッシュをクリアします。プッシュのバインド解除に必要なインストール資格情報と保留中の再試行が残る場合があります。システム バックアップ、他のデバイス上のコピー、およびキーチェーンは、アンインストールまたは 1 回のクリーンアップ操作によって完全に削除されたと想定してはなりません。

8. セキュリティとインシデント対応

API およびリアルタイム接続では、デフォルトで HTTPS/WSS が使用されます。資格情報はリクエスト ヘッダーまたは接続認証フレームで送信され、リクエスト URL に直接含めることは避けられます。クライアントはエンドツーエンドの暗号化を実装しません。ローカル ファイルはシステム ファイル保護を使用します。ローカル保護とトランスポート暗号化では、デバイスの盗難、受信者による再配布、サーバー攻撃などのリスクを排除できません。

デバイスのロック解除認証情報を保護し、パスワードや確認コードを共有しないでください。共有デバイスでサインアウトした後、下書きと通知設定を確認します。アカウントの盗難または情報漏洩の疑いがある場合は、パスワードを変更し、電子メールでサポートに連絡してください。個人情報セキュリティインシデントが発生した場合は、是正措置と、該当する場合、影響を受ける人々および当局への通知が必要です。このポリシーは法的責任を放棄するものではありません。

9. 選択とデータ権利の要求

アクセスと修正: プロフィールの情報を管理し、プロフィールと関連コンテンツ ページを編集します。プライバシー設定では、プロフィール、デフォルトの投稿対象者、電子メールの表示、検索、友達リクエストを制御します。以前に公開されたコンテンツの視聴者を個別に確認してください。写真または通知の許可を拒否すると、対応するオプション機能にのみ影響します。

同意を取り消す: [設定] → [個人情報とアクセス許可] → [同意を取り消してサインアウト] を選択します。クライアントは現在のアカウント サービスを停止し、オフライン情報に戻ります。出金はアカウントの削除ではなく、出金前の合法的な処理には影響しません。別の法的根拠に基づいて保持が継続される場合は説明が必要であり、許可が取り消された無関係な使用を継続することはできません。

アカウントの削除: [設定] → [アカウントの削除] で、情報を読み、表示された確認の言葉を入力し、もう一度確認してサーバーに適用します。成功するとサインアウトされ、関連するローカル データが消去されます。失敗するとエラーが表示されます。ボタンをタップしたり、ネットワーク タイムアウトが発生しても、削除は完了しません。削除を元に戻すことはできません。まず、法的に保持する権利がある情報を保存してください。サーバーの処理と現在の制限については、セクション 7 を参照してください。

情報へのアクセス、コピー、補足、修正または削除、ルールの説明の取得、または異議の申し立てをするには、{{contactEmail}} まで電子メールを送信してください。 「個人データのリクエスト」、アカウントの電子メールまたはユーザー ID、特定のリクエストとデータの範囲を含めます。 [設定] → [連絡先と苦情] で、リクエストの種類を選択し、詳細を準備して電子メールを開くか、アドレスをコピーして自分で送信します。このページでは、下書き、チャット、アカウント情報が自動的にアップロードされません。電子メールを開いたからといって送信が成功したわけではありません。相応の本人確認が必要な場合があり、エージェントには適切な許可が必要です。パスワード、確認コード、または無関係な完全な身分証明書を直接提供しないでください。要求に応じられない場合は、理由と異議申し立てまたは苦情の手段を提供する必要があります。これは、法律に基づいて管轄当局に連絡するお客様の権利には影響しません。

公開コンテンツ、チャット、または検証資料を通じて、未成年者に関する無関係の機密情報を送信しないでください。適切な許可のない処理を発見した保護者は、問題を特定するために必要な最小限の情報のみを提供して、削除またはその他の権利を求めるためにこのポリシーに記載されている電子メールに連絡することができます。

11. アップデートとアクセス

初めて使用するときに、サインイン ページまたは [設定] → [プライバシー ポリシー] でこのポリシーをお読みください。その内容を使用してセクションを移動するか、システム共有シートを使用して全文を保存します。ポリシー ページには、利用規約、コミュニティ ガイドライン、お問い合わせツールへのリンクもあります。クライアントは同意のバージョンと時間をローカルに記録します。ポリシー、規約、コミュニティ ルール、または動作設定を変更すると、アカウント サービスが再開される前に、別のプレゼンテーションが要求されます。重要な変更は明確に説明する必要があります。新しいバージョンを拒否しても、オフラインでの閲覧は可能です。法律で義務付けられている場合、継続使用は新たな同意に代わるものではありません。
