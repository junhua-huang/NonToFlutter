# 南图：2026-10-28 客户端修复

- 受限主页显示访问说明；仅好友主页仍可申请、接受或取消好友申请。其他用户主页的动态不再从旧本机列表缓存抢先显示。
- 列表尊重服务器明确的 `has_more`，允许继续经过空页；连续 5 个空页暂停自动请求并允许手动继续，重复非空页停止，避免无限自动加载。
- 举报记录只使用 `reporter_notice` 显示处理反馈，忽略旧服务器和旧缓存中的内部处理原因、管理员编号。
- 配套服务端改密成功后退出账号并提示使用新密码登录，旧设备会话及推送绑定由服务端撤销。
- 发布草稿在本机 Application Support 中按账号、社群、引用上下文隔离。原子索引保存文字、范围、身份、附件顺序和媒体，保留相册去重标识；媒体不存入 UserDefaults。
- 文件采用 iOS 完整文件保护并排除备份。文件写入在串行 actor 中进行，过时写入不得覆盖新草稿或复活已放弃内容。保留并关闭等待保存成功；保存失败保留编辑页。发布、放弃或注销会清理对应文件。
- 旧版文字草稿继续兼容，恢复异常时保留能读取的文字并显示提示。清理缓存和退出登录保留草稿，注销后清理。

本次按用户要求未运行测试、未使用真机或模拟器调试。发行流程仅执行编译、签名和归档。
